How it works

1

You provide the video

Upload a file from your device, or paste a public YouTube link. Nothing is stored on any server belonging to this site — there isn't one.

2

Gemini watches it

Your browser sends the video straight to Google's Gemini API, which samples frames across the full duration and understands motion, collisions and context — not just single images.

3

Incidents are extracted

A structured prompt asks for every accident and near-miss as data: timestamps, type, severity, confidence, vehicles involved, visible injuries.

4

You review the report

Incidents appear as clickable markers on your video's timeline. Export the full report as JSON for records, claims or fleet logs.

FAQ

Where does my video go?

From your browser directly to Google's Gemini API — either inline with the request (small clips) or via Google's File API (larger files, auto-deleted after 48 hours). This website is static hosting on GitHub Pages: it has no backend, no database and no analytics.

Is my API key safe here?

It is saved only in your browser's local storage and sent only to generativelanguage.googleapis.com. Anyone with your key can spend your quota, so don't paste it on shared computers — use the Clear button when you're done.

What does it cost?

Gemini's free tier covers generous daily usage — video analysis of typical clips costs fractions of a cent on paid tiers. Check Google AI Studio for current quotas.

How accurate is it?

Very good at spotting visible collisions, rollovers, pedestrian impacts and dramatic near-misses. It can miss subtle events in dark, blurry or distant footage. Treat the report as an assistant's first pass, not a certified finding — always verify critical timestamps yourself.

What are the limits?

Files up to 2 GB; YouTube links must be public videos. Very long videos (30+ minutes) take several minutes to process and analyze — the progress bar keeps you posted.

Can it watch a live camera feed?

Not in this version — it analyzes recorded video files and YouTube links. Live-stream analysis is on the roadmap.
